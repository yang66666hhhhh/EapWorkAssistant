# 仪表盘 StatCard 趋势胶囊接入完成

把上一轮已就绪但未接数据的 StatCard 趋势胶囊（涨红跌绿）正式接入仪表盘真实数据。

## 改动清单

### 1. 仓库新增按日期范围计数（3 个文件）
- `Repositories/WorkRecordRepository.cs` — `GetCountByDateRangeAsync`（按 `WorkDate BETWEEN`）
- `Repositories/IssueRepository.cs` — `GetCountByDateRangeAsync`（按 `date(CreateTime) BETWEEN`，规避 CreateTime 含时分秒导致字符串比较失效）
- `Repositories/KnowledgeRepository.cs` — 同上

### 2. ViewModel 计算并暴露趋势（`ViewModels/DashboardViewModel.cs`）
- 新增 6 组属性：`Today/Week/Month/Records/Issues/Knowledge` 的 `TrendText` / `TrendUp`
- 新增助手 `ComputeTrend(current, previous)`：
  - 上期 = 0 且本期 > 0 → 显示「新」（向上箭头，冷启动场景）
  - 两者皆 0 → 空，不显示胶囊
  - 否则显示 `±NN%`，方向按 本期 ≥ 上期
- `LoadDashboardAsync` 中计算：
  - 工时卡：**今日 vs 昨日 / 本周 vs 上周 / 本月 vs 上月**
  - 计数卡：**本月新增 vs 上月新增**（记录数 / 待解决问题 / 知识条目）

### 3. View 绑定（`Views/DashboardView.xaml`）
- 6 张 `StatCard` 全部绑定 `TrendText` / `TrendUp`

## 设计说明
- 全部复用既有令牌与 `TrendBrushConverter`（涨红跌绿，符合中国习惯），未新增颜色、未硬编码。
- 计数卡的数值是累计总量、趋势是「本月新增环比」——属常见看板做法（总值 + 周期增量）。
- 不破坏任何现有调用：未传 `TrendText` 的 StatCard（如其它页面）仍按原样显示（胶囊 `Visibility` 为空即隐藏）。

## 验证
隔离编译（`obj/_verify_trend` / `bin/_verify_trend`）：**0 错误**，仅 SkiaSharp NU1701 无害警告；临时产物已清理。
