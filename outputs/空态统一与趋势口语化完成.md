# 组件升级·三阶段：统一空状态 + 趋势口语化

完成时间：2026-08-27｜编译状态：隔离编译 0 错误（仅 SkiaSharp NU1701 无害警告）

## 一、空状态统一（EmptyState 正式接线）

上一阶段已交付 `Controls/EmptyState` 组件，但各页空态仍是散落的内联 `Path + 文字`。本次把 4 个主列表页的「暂无 X」空态整体替换为统一组件，复用既有图标与文案：

| 页面 | 原空态 | 图标 |
|---|---|---|
| RecycleBinView | 回收站是空的 | IconRecycleEmpty |
| IssueView | 暂无问题记录 | IconWrench |
| KnowledgeView | 暂无知识条目 | IconBook |
| WorkRecordView（×2） | 当日暂无工作记录 / 暂无匹配的工作记录 | IconPencil / IconSearch |

**保留不动**：各页「搜索无结果」态（含动态 `SearchKeyword` 关键词高亮）。因 `EmptyState.Description` 为纯字符串、无法嵌入关键词，维持原「与通用空态区分」设计。

**规范遵循**：仅替换内层内容，外层 `Border` 的 `Visibility` 绑定（`CountToVisibilityConverter` / `BoolToVis`）与 `Card` 样式全部保留；未新增命名空间（各视图已声明 `xmlns:controls`）；未硬编码颜色，组件内部复用 `PrimarySoftBrush` / `TextPrimaryBrush` 等令牌。

## 二、趋势胶囊文案口语化

`DashboardViewModel.ComputeTrend` 新增 `periodLabel` 参数，六张统计卡的趋势胶囊从裸百分比升级为：

- 今日工时 → **较昨日 ±NN%**
- 本周工时 → **较上周 ±NN%**
- 本月工时 / 记录数 / 待解决问题 / 知识条目 → **较上月 ±NN%**
- 冷启动（上期 0、本期有数据）→ 仍显示「新」（向上箭头，不带前缀）

涨红跌绿语义不变（`TrendBrushConverter`，符合中国习惯）。

## 五、紧凑模式实现要点（补充）

`EmptyState.xaml` 重写时把所有可变属性（插画宽高/圆角、图标宽高、标题/描述字号字重前景边距、StackPanel 边距最大宽）从「本地属性」改为 **Style Setter 默认值 + DataTrigger(IsCompact=True) 覆盖**。这是 WPF 依赖属性优先级要求——本地属性（XAML 特性）优先级高于 Style 触发器，若保留本地属性则触发器不会生效。紧凑态数值：插画 32×32（`RadiusMd`）、图标 18×18、标题 `FontSizeMd`/SemiBold/`TextTertiaryBrush`、描述 11、StackPanel `Margin=12` `MaxWidth=260`。
